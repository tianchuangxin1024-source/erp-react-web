# 衡账 · 财务管理系统

基于财务管理系统 PRD 的 React 前端原型，包含财务工作台及八个业务模块。

## 本地运行

```powershell
npm ci
npm run dev
```

打开 Vite 输出的本地地址。演示账号为 `admin`，密码为 `Admin123`，登录页也可一键填入。刷新页面会保留当前标签页的演示会话，可通过工作台右上角退出。

查询、新增、审核、导出等业务操作会打开接口说明弹窗，显示该操作所需的接口功能和当前参数。工作台指标及标记为「演示记录」的表格使用静态示例。登录仅在浏览器中模拟，接入真实系统时需由后端校验账号和业务权限。

运行 `npm run build` 生成生产构建。

## 目录结构

- `src/app` 负责应用入口、路由、登录拦截和工作台布局。
- `src/pages` 按页面组织代码，页面目录下的 `views` 放置该页面的表单、表格和图表等视图。
- `src/features/auth` 管理演示登录与会话。`src/features/finance/model/modules` 按业务模块维护页面字段、示例数据和接口说明。
- `src/shared` 放置可复用组件、基础样式和通用样式。

修改业务页的查询条件、列或操作时，编辑对应模块的配置。通用查询和表格交互位于 `src/pages/finance`。注册新的业务页时，将定义加入该模块的 `pages` 数组，路由和侧栏菜单会从同一份配置生成。
